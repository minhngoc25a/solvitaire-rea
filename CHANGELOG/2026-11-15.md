# Changelog — 2026-11-15

## Course correction review (no source changes)

- Added `docs/RECONSTRUCTION_PLAN.md`, which replaces the "make the refactored source compile" loop with this pipeline: golden API test → bytecode remap → decompile → per-class compile → full build checked against the golden output.
- Added a course-correction banner to `PROJECT_STATUS.md`.
- Findings, all reproduced from the shipped JAR and the current tree:
  - The obfuscator uses case-only-distinct class names (`qo`/`qO`, `g`/`G`). CFR renamed 494 of them to `*_0` on Windows.
  - The obfuscator uses keyword class names (`do`).
  - The obfuscator uses same-name fields of different types; `qo` has 2× each of `a`…`h`.
  - The refactor's `a → AboutDialog` rename was a text replace. It left 4,668 tokens and changed string literals on 175 lines.
  - The DLL exports `Java_com_solvitaire_app_WinUser32_*`. Moving the class to `...solitaire.jni` breaks native linkage.
  - Raw CFR output gives 353 errors, all parse errors. javac stops before attribution, so the true semantic error count is unknown.
