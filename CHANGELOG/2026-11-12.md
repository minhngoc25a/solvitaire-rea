## Caveats (pre-existing bugs in the shipped build, not introduced here)

- `mode play` crashes with `ArrayIndexOutOfBoundsException` if `reset` was sent before it on the same launch — do not `reset` between launch and `mode play`. Issue occurs in the mode-selector dialog (`G.g` indexes past a 5-token split).
- Bare commands (no `^<macro>` prefix) crash the API input thread (`var2_15[1]` out of bounds).
