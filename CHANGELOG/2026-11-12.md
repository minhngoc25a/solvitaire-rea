## Installer analysis (2026-11-12)

Analyzed the InstallForge installer `solvitaire_installv5.3.3.exe` (PE32 x86, 37.8 MB, zeroed section table). `FUN_00411ef0` (17,349 bytes) is the installer main logic. Full flow documented in `docs/FILE_FORMATS.md`:

- **Two embedded 7z archives:** SETUPCONFIGURATION at offset 1371408 (11 installer data files), main payload at offset 1409045 (171 game payload files)
- **Singleton mutex:** `__InstallForgeSetup__` (exits if already running)
- **GUID:** CoCreateGuid + StringFromGUID2 for setup instance ID
- **Install dir:** `FUN_004171d5` strips `\\?\` prefix from module path, truncates at last `\`; `FUN_00401560` → SHCreateDirectory
- **SETUPCONFIGURATION from PE resource:** LoadLibraryW(self) → FindResourceW(RT_RCDATA 0xa, "SETUPCONFIGURATION") → LoadResource/LockResource/SizeofResource → FUN_0041f260/open → FUN_0041f580/4KB buffer → FUN_0041f9e0/read → FUN_0041f1a0/flush+close

- **Entry chain:** `entry` (0x00401590) → `__set_app_type(2)` → `FUN_00401180` (CRT main) → `FUN_0040ba30` (cmd-line parse) → `FUN_00401803` (Launch4j WinMain) → `FUN_00404890` (JNI/Java launch)
